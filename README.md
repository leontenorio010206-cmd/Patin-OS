# Patiñ Os

Simulador experimental de circuitos lógicos para Android, basado en un editor táctil offline y con importación parcial de archivos `.dig` de [Digital](https://github.com/hneemann/Digital).

Versión inicial: `0.2.1-alpha`. El código Android y la compilación de APK se incorporan en los commits de arranque. No es una distribución oficial de Digital.
